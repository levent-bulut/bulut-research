FRAMEWORK

Narrative Gravity

Narrative Gravity is a framework within Narrative Engineering that examines the forces that attract, stabilize and organize narrative structures around central informational elements.

Official Website Corpus GitHub

Description

Narrative Gravity describes how certain events, concepts or narrative elements become dominant organizing centers within a story, influencing the distribution and interpretation of surrounding information.
