FRAMEWORK

Narrative Entropy

Narrative Entropy is a theoretical framework within Narrative Engineering that examines the distribution, degradation and organization of narrative information throughout a story.

Official Article Corpus GitHub

Description

Narrative Entropy provides a conceptual framework for analysing how narrative information changes over time, how order and uncertainty emerge, and how story structure can be examined from an information-oriented perspective.
