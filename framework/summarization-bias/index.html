FRAMEWORK

Summarization Bias

Summarization Bias describes the tendency of large language models to compress objective narrative evidence into high-level semantic labels, potentially altering the informational structure of a narrative.

Official Website Corpus GitHub

Description

The framework investigates whether automated summarization systems preserve objective projection or replace it with abstract interpretive statements. It provides a conceptual basis for evaluating narrative preservation in large language models.
